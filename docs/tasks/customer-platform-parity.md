## Rules and dependencies retained

- Shared constants/types remain authoritative for statuses, methods and state transitions. No new business status, permissions grant or mutation endpoint.
- API validation/access/action metadata remains authoritative; source payments, Wages, Kharchi and booking retry behavior is preserved.
- Organization/project scope is explicit where provided; unknown target IDs never select a different project. Native default navigation still uses the active project.
- Worker lifecycle clarification is owner-approved in `docs/decisions/007-worker-deactivation-preserves-assignments.md`. Deactivation preserves assignments/history. Permanent deletion is separately confirmed and requires organization-level workers:delete, never a custom project-only grant.
- Added native labels/messages are in en/hi/gu. Existing native components/design tokens are used. The optional ui-ux-pro-max companion skill was unavailable.
- CSV uses current API filters, private authenticated requests and explicit user save/share. Existing PDFs stay available. Temporary native CSV files are removed after sharing. No offline write queue, DB mutation, schema rollout, outbound message or deployment occurred.
