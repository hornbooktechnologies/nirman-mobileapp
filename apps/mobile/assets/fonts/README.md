# Bundled Mobile Fonts

NirmanSite bundles these font families for offline mobile UI rendering:

- Manrope for English;
- Noto Sans Devanagari v2.006 for Hindi;
- Noto Sans Gujarati v2.106 for Gujarati.

The Noto static Regular, Medium, SemiBold, and Bold files were copied from the
official Noto release archives:

- <https://github.com/notofonts/devanagari/releases/tag/NotoSansDevanagari-v2.006>
- <https://github.com/notofonts/gujarati/releases/tag/NotoSansGujarati-v2.106>

The corresponding OFL notices are retained in this directory as
`NotoSansDevanagari-OFL.txt` and `NotoSansGujarati-OFL.txt`.
